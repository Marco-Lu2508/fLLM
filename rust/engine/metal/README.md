# Metal shaders

MSL sources (`*.metal`). `build.rs` (feature `metal`, any host) embeds them into `metal_sources.rs`; the backend compiles them at start with `newLibraryWithSource` (a precompiled `.metallib` through `xcrun metal` is optional and done on macOS). Shared code goes to `common.metal` (listed first). The quantized linear family is described in `INTERFACE_QUANT.md` (formats: GGUF block formats, MXFP4/NVFP4, AWQ/GPTQ, MLX affine, block-wise FP8, bitsandbytes, EXL2; `q_gen.py` generates the instantiation files `q_mv_*.metal` / `q_mm_*.metal`); `emu/` has the CPU emulation and the C++ decoder checks (`emu/README.md`). The kernels of the newer families (MLX, FP8B, bitsandbytes, EXL2) have only been linted and emulated, never compiled by Metal.
