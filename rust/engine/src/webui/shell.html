Tools (MCP)

                
Model Context Protocol servers give the model extra tools (files, search, databases, ...). Each server is a program that fLLM starts on this computer.

                
Warning: an MCP server runs with your user rights and can read, change and delete what you can. Only add servers you trust, and check the command and arguments.

Model providers

                
Use models of other servers and cloud services (OpenAI-compatible services, Anthropic, Ollama, LM Studio, vLLM) in the chat, next to the model on this computer. They appear in the model menu as "Provider · model".

                
Privacy: everything you type in a chat with such a model is sent to that service. Keys are stored in a file on this computer and are never shown again; this page never receives them, fLLM adds them when it passes your request on.
